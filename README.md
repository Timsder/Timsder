# Schnittwerk – Download

**[Schnittwerk-1.0.0-Setup.exe herunterladen](https://github.com/Timsder/Timsder/raw/schnittwerk-download/Schnittwerk-1.0.0-Setup.exe)** (ca. 100 MB, Windows 64-Bit)

Setup starten und dem Assistenten folgen. Danach liegt Schnittwerk auf dem Desktop und im Startmenue.
Windows kann warnen, weil das Setup nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausfuehren“.

Deinstallieren: Einstellungen → Apps → Schnittwerk.
